# Felipe Lopes

Desenvolvedor **full-stack** e fundador da **[FML Tech](https://fmlsoftware.com.br)**, software house de Novo Hamburgo/RS focada em SaaS B2B, agentes de IA e blockchain.

Construo produtos de ponta a ponta: arquitetura, backend, frontend, serviços de IA e infraestrutura. Bacharel em Ciência da Computação (Feevale), com especialização em segurança de redes.

### Stack

- **Backend:** PHP · Laravel · Node.js · Python · FastAPI · Filas (Horizon, Redis, SQS) · WebSockets (Reverb)
- **Frontend:** TypeScript · React · Next.js · Vue.js · Tailwind
- **IA:** LangGraph · RAG com embeddings (pgvector) · Servidores MCP · OpenAI · Gemini
- **Blockchain:** Tokenização de ativos · NFTs · Polygon · Ethereum · Ethers.js
- **Dados e infra:** MySQL · PostgreSQL · Redis · Docker · AWS (S3, SQS) · GitHub Actions
- **Arquitetura:** SaaS multi-tenant e white-label · Microsserviços · Monorepos · Integração com WhatsApp Cloud API
